# Security and actors

The default actor resolver uses the authenticated principal's name and leaves the optional actor ID empty. Replace it when the application has a stable domain identifier. System and unauthenticated operations produce `actor: null` rather than an invented user.

The default read authorizer accepts any authenticated caller. Production applications should usually replace it with entity-aware policy.
