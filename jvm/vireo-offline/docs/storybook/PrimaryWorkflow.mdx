# Primary workflow

Most queued mutations replay through the authenticated HTTP endpoint automatically. Add an ordered handler when a domain command should execute without looping through the web stack.

## Why it exists

Custom replay often needs application services, typed payload parsing, and permanent-versus-retryable classification. The handler seam supplies that behavior without exposing Offline's mutable persistence entity or transferring retry ownership to application code.
