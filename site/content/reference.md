# Reference

Reference documentation is exhaustive and version-specific. Most developers should begin with the task-oriented [Vireo documentation](/docs/) and open reference only when an exact export, signature or JVM member is needed.

## TypeScript

The generated TypeScript reference is derived from checked public package entry points, API-surface snapshots and emitted declarations. It includes every declared export without encouraging unsupported deep imports.

[Open TypeScript API reference](/reference/typescript/)

## Java

The Java reference is aggregate Javadoc for the coordinated public JVM module family.

[Open Java API reference](/reference/java/)

## Interactive UI catalogue

Storybook is not an API dump. It is the live visual reference for component behavior and examples.

[Open Storybook](/storybook/)

## Exact release identity

Reference URLs use the immutable machine release `{{EXACT_RELEASE_ID}}`. The friendly documentation navigation uses Vireo `{{DOCS_VERSION}}`. [Versions](/versions/) records their mapping.
