# Java API reference

The Java reference contains aggregate Javadocs for the public `com.vireocode` module family and every published public member.

## Before using it

Begin with [Spring Boot foundations](/docs/spring/) and the application architecture guides. Javadocs provide exact type and member contracts, not a recommended application design by themselves.

## Align modules with the BOM

Use `vireo-bom` rather than selecting unrelated module versions. A Javadoc page being reachable does not imply that mixing arbitrary release lines is supported.

Application domain types, services and authorization policy remain outside the framework reference.
