# Interactive Storybook

Storybook is Vireo's visual laboratory. It complements the main guides with live component states, controls and responsive examples.

## Use Storybook for

- Component variants and supported composition
- Loading, empty, failure and disabled states
- Responsive and narrow-layout behavior
- Keyboard and accessibility-oriented examples
- Integration-specific examples
- Visual regression and component authoring context

## Use the main documentation for

- Choosing a project profile
- Understanding architecture and ownership
- Connecting company APIs
- Generating capabilities
- Deployment, security and upgrades
- Deciding when a component pattern is appropriate
