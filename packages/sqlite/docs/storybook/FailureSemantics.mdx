# Failure semantics

Invalid worker and entity configuration fails synchronously. Handler collisions never overwrite an earlier operation. Disposed runtimes reject every later request.

At runtime, Worker crashes reject pending work and tear down the failed generation so a later request can initialize a fresh Worker. Migration errors roll back. Corrupt persisted queue JSON throws with its command identifier instead of replaying fallback data.
