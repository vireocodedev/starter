# Offline utilities

The `/offline` entry point is transport-neutral. It provides paged snapshot collection, offline mutation ordering, normalized replay headers, queueability policy, and network-status state without opening SQLite or constructing a Worker.

Sensitive headers are intentionally excluded from replay. Applications decide whether the default endpoint and method policy is sufficient or pass explicit policy options.
