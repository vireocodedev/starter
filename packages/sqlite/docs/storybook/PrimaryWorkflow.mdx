# Primary workflow

An entity bundle is the single source for row conversion, generated worker operation names, request payload keys, and CRUD handlers. The worker configuration combines bundles, ordered migrations, and explicit extra handlers.

Duplicate operation names and invalid configuration throw while the worker module is being constructed, before a request can reach the database.
