## RgoLocalStorageService

A type-safe wrapper around `localStorage` with automatic initialization of default values and JSON serialization.

### Setup

```tsx
import { RgoLocalStorageService } from "@vireocodedev/starter-ui";

// Define your storage schema
type AppSettings = {
  theme: "light" | "dark";
  language: string;
  sidebarCollapsed: boolean;
  recentItems: string[];
};

// Create the service with default values
const settingsStorage = new RgoLocalStorageService<AppSettings>({
  theme: "light",
  language: "en",
  sidebarCollapsed: false,
  recentItems: [],
});
```

### Usage

```tsx
// Get a value (type-safe)
const theme = settingsStorage.get("theme"); // "light" | "dark"

// Set a value (type-safe)
settingsStorage.set("theme", "dark");

// Arrays are handled correctly
const items = settingsStorage.get("recentItems"); // string[]
settingsStorage.set("recentItems", [...items, "new-item"]);
```

### Behavior

- On first access of a key, it checks localStorage. If missing or unparseable, it initializes with the default value.
- All values are stored as JSON strings.
- Full TypeScript inference for keys and value types.

## RgoOfflineCacheService

An IndexedDB-backed offline cache service using the `idb` library. Supports versioned schema upgrades and bulk data loading.

### Setup

```tsx
import { RgoOfflineCacheService } from "@vireocodedev/starter-ui";
import type { DBSchema } from "idb";

// Define your IndexedDB schema
interface MyDBSchema extends DBSchema {
  users: {
    key: number;
    value: { id: number; name: string; email: string };
  };
  products: {
    key: string;
    value: { sku: string; name: string; price: number };
  };
}

// Define stores with key paths
const stores = {
  users: { keyPath: "id" },
  products: { keyPath: "sku" },
};

// Create the service
const offlineCache = new RgoOfflineCacheService<MyDBSchema>(stores, {
  version: 1,
  debug: false,
});

// Initialize (opens/upgrades the database)
await offlineCache.init();
```

### Usage

```tsx
// Load data into the cache (clears existing data first)
await offlineCache.loadCache({
  users: [
    { id: 1, name: "Alice", email: "alice@example.com" },
    { id: 2, name: "Bob", email: "bob@example.com" },
  ],
  products: [{ sku: "A001", name: "Widget", price: 9.99 }],
});

// Access the IDB database directly for reads
const db = offlineCache.db;
const user = await db.get("users", 1);
const allProducts = await db.getAll("products");
```

## RgoWebWorkerService

A typed web worker communication service with event-based messaging.

### Setup

```tsx
import { RgoWebWorkerService } from "@vireocodedev/starter-ui";

// Define message schemas for both directions
type WorkerToMain = {
  result: { data: number[] };
  progress: { percent: number };
  error: { message: string };
};

type MainToWorker = {
  process: { input: number[] };
  cancel: undefined;
};

// Create the service
const worker = new RgoWebWorkerService<{
  incoming: WorkerToMain;
  outgoing: MainToWorker;
}>({
  worker: new Worker(new URL("./my-worker.ts", import.meta.url)),
  onInit: () => console.log("Worker initialized"),
});

// Initialize
worker.init();
```

### Usage

```tsx
// Listen for messages from the worker (typed)
worker.on("result", data => {
  console.log("Received result:", data.data);
});

worker.on("progress", data => {
  console.log(`Progress: ${data.percent}%`);
});

// Send messages to the worker (typed)
worker.emit("process", { input: [1, 2, 3, 4, 5] });
worker.emit("cancel");
```

### Worker-Side Example

```tsx
// my-worker.ts
self.onmessage = (e: MessageEvent) => {
  const { type, payload } = e.data;

  if (type === "process") {
    const result = payload.input.map((n: number) => n * 2);

    self.postMessage({ type: "progress", payload: { percent: 50 } });
    self.postMessage({ type: "result", payload: { data: result } });
  }
};
```
