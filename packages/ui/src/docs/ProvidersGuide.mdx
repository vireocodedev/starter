## Provider Nesting Order

Providers should be nested in this recommended order (outermost → innermost):

```tsx
import {
  RgoThemeProvider,
  RgoQueryClientProvider,
  RgoLocalizationProvider,
  RgoIconsProvider,
  RgoConfirmProvider,
  RgoSnackbarProvider,
} from "@vireocodedev/starter-ui";

function App() {
  return (
    <RgoThemeProvider theme={theme}>
      <RgoQueryClientProvider client={queryClient}>
        <RgoLocalizationProvider>
          <RgoIconsProvider icons={icons}>
            <RgoConfirmProvider>
              <RgoSnackbarProvider>
                <YourApp />
              </RgoSnackbarProvider>
            </RgoConfirmProvider>
          </RgoIconsProvider>
        </RgoLocalizationProvider>
      </RgoQueryClientProvider>
    </RgoThemeProvider>
  );
}
```

## RgoThemeProvider

**Required** — wraps the app in MUI `ThemeProvider` and applies `CssBaseline`.

```tsx
import { createTheme } from "@mui/material/styles";
import { RgoThemeProvider } from "@vireocodedev/starter-ui";

const theme = createTheme({
  palette: {
    primary: { main: "#1976d2" },
  },
});

<RgoThemeProvider theme={theme}>
  <App />
</RgoThemeProvider>;
```

## RgoLocalizationProvider

Sets up MUI date/time localization with `dayjs` adapter and registers `i18n-iso-countries` locales (bs, de, en, hr, it, pt, sl). Waits for i18next to be ready before rendering children.

```tsx
import { RgoLocalizationProvider } from "@vireocodedev/starter-ui";

<RgoLocalizationProvider>
  <App />
</RgoLocalizationProvider>;
```

No props required. Uses the i18n instance configured elsewhere.

## RgoConfirmProvider

Provides imperative confirmation dialogs via the `useRgoConfirm` hook.

```tsx
import { RgoConfirmProvider, useRgoConfirm } from "@vireocodedev/starter-ui";

// In your provider tree
<RgoConfirmProvider>
  <App />
</RgoConfirmProvider>;

// In any component
function DeleteButton() {
  const confirm = useRgoConfirm();

  const handleDelete = async () => {
    const confirmed = await confirm({
      title: "Delete Item",
      message: "This action cannot be undone.",
      confirmText: "Delete",
      cancelText: "Cancel",
      color: "error",
    });

    if (confirmed) {
      // proceed with deletion
    }
  };

  return <button onClick={handleDelete}>Delete</button>;
}
```

### Static Access

For showing snackbars outside React components:

```tsx
import { showNotiSnackStatic, closeNotiSnackStatic } from "@vireocodedev/starter-ui";

// From an API interceptor, service, etc.
const id = showNotiSnackStatic("Operation completed", { variant: "success" });
closeNotiSnackStatic(id);
```

## RgoIconsProvider

Provides a type-safe icon registry. Icons are registered by the consumer app through TypeScript interface augmentation.

### Step 1: Augment the Registry

```tsx
// In your app's type declarations (e.g., icons.d.ts)
import type { SvgIconComponent } from "@mui/icons-material";

declare module "@vireocodedev/starter-ui" {
  interface RgoIconRegistry {
    home: SvgIconComponent;
    settings: SvgIconComponent;
    delete: SvgIconComponent;
  }
}
```

### Step 2: Provide the Icons

```tsx
import { RgoIconsProvider } from "@vireocodedev/starter-ui";
import HomeIcon from "@mui/icons-material/Home";
import SettingsIcon from "@mui/icons-material/Settings";
import DeleteIcon from "@mui/icons-material/Delete";

const icons = { home: HomeIcon, settings: SettingsIcon, delete: DeleteIcon };

<RgoIconsProvider icons={icons}>
  <App />
</RgoIconsProvider>;
```

### Step 3: Use Icons

```tsx
import { useRgoIcons, RgoIcon } from "@vireocodedev/starter-ui";

// Via hook
function MyComponent() {
  const { muiIconsMap } = useRgoIcons();
  const HomeIcon = muiIconsMap.home;
  return <HomeIcon />;
}

// Via component
<RgoIcon name="home" fontSize="large" color="primary" />;
```

## RgoSseProvider

Manages Server-Sent Events (SSE) connections with typed event handlers.

```tsx
import { RgoSseProvider } from "@vireocodedev/starter-ui";

<RgoSseProvider
  url="/api/events"
  eventHandlers={{
    notification: data => handleNotification(data),
    update: data => handleUpdate(data),
  }}
  withCredentials
>
  <App />
</RgoSseProvider>;
```

## RgoProviders Utility

A utility component that reduces provider nesting boilerplate by composing multiple providers:

```tsx
import { RgoProviders, RgoThemeProvider, RgoConfirmProvider, RgoSnackbarProvider } from "@vireocodedev/starter-ui";

const providers = [
  props => <RgoThemeProvider theme={theme} {...props} />,
  props => <RgoConfirmProvider {...props} />,
  props => <RgoSnackbarProvider {...props} />,
];

<RgoProviders list={providers}>
  <App />
</RgoProviders>;
```

This is equivalent to manually nesting the providers but keeps the code flat and composable.
