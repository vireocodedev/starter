## Overview

The RGO Front-UI form system is built on top of **React Hook Form** and **Zod validation**, providing a robust, type-safe, and performant form handling solution. Our architecture emphasizes:

- **Type Safety**: Full TypeScript support with proper type inference
- **Performance**: Minimal re-renders and optimized form state management
- **Validation**: Schema-based validation with internationalization support
- **Consistency**: Standardized patterns across all form components
- **Accessibility**: WCAG compliant components with proper ARIA attributes
- **Developer Experience**: Clear APIs, comprehensive documentation, and reusable patterns

## Features

- **Schema-Based Forms**: Built on Zod validation with TypeScript type inference for compile-time safety
- **React Hook Form Integration**: Leverages React Hook Form for optimal performance and minimal re-renders
- **Internationalized Validation**: Validation messages support translation functions for multi-language applications
- **Dynamic Array Fields**: Full support for dynamic form arrays with add/remove functionality via `useFieldArray`
- **Responsive Grid Layout**: Built-in responsive grid system using Material-UI Grid2 components
- **Component Composition**: Flexible `ContentComponent` and `ActionsComponent` props for customizable layouts
- **Field State Management**: Automatic error handling and field state tracking with `Controller` integration
- **Read-Only Mode**: Built-in support for read-only forms via `readOnly` prop propagation
- **Mutation Integration**: Seamless React Query `useMutation` integration for form submission
- **Standardized Props**: Consistent `RgoFormBaseProps` interface across all form components
- **Label and Helper Text**: Rich labeling system with `RgoLabelBox` supporting helper text and actions
- **Form Grouping**: Legacy examples below use Grid2; new Vireo forms use the container-aware form layout contract
- **Empty State Handling**: Built-in empty state displays for array fields with custom messaging
- **Error Boundaries**: Array-level and field-level error message display with proper styling

## Usage

This guide demonstrates how to create forms using the RGO Front-UI form system. The process is structured into clear steps that build upon each other, from defining your data model to implementing the complete form component.

### Model schema

Start by creating a Zod schema and TypeScript type for your form data.

```tsx
/*** @/features/demo/models/Demo.ts ***/

import z from "zod";

// ⭐ Define and export the zod schema respective to the data model
export const Demo = z.object({
  name: z.string(),
  email: z.string(),
  age: z.number().nullable(),
  hobbies: z.array(z.string()),
});

// ⭐ Export inferred TypeScript type under the same name
export type Demo = z.infer<typeof Demo>;
```

### Model default values

Create and export a constant with default values for your form.

```tsx
/*** @/features/demo/models/Demo.ts ***/

// ⭐ Define and export default values matching the data model
export const DEMO_DEFAULT: Demo = {
  name: "",
  email: "",
  age: null,
  hobbies: [],
};
```

### Model validation schema

Create a validation schema function that accepts translation functions for internationalized error messages.

```tsx
/*** @/features/demo/models/Demo.ts ***/

import { type UseFormSchema } from "@vireocodedev/starter-ui";
import z from "zod";

// ⭐ Define and export validation schema with translated error messages
export const demoSchema: UseFormSchema<Demo> = t => {
  return Demo.extend({
    name: z.string().min(1, t("validation.required")),
    email: z.string().email(t("validation.invalidEmail")),
    age: z.number().min(18, t("validation.minimumAge", { min: 18 })),
    hobbies: z.array(z.string().min(1, t("validation.required"))
      .min(1, t("validation.required")),
  });
};
```

### Form submission and invocation

Handle form submission using React Query's `useMutation` and pass the submit handler to `RgoForm`.

```tsx
/*** @/features/demo/components/DemoForm/DemoForm.tsx ***/

import { demoSchema, DEMO_DEFAULT } from "@/features/demo/models/Demo";
import { type RgoFormBaseProps, RgoForm, RgoFormGroup, useRgoForm } from "@vireocodedev/starter-ui";
import { CardActions, CardContent } from "@mui/material";
import { useMutation } from "@tanstack/react-query";
import "./DemoForm.css";

export type DemoFormProps = RgoFormBaseProps<Demo>;

export function DemoForm({
  form,
  onCancel,
  readOnly = false,
  group = RgoFormGroup.CREATE,
  ContentComponent = CardContent,
  ActionsComponent = CardActions,
}: DemoFormProps) {
  const form = useRgoForm({
    schema: demoSchema,
    defaultValues: DEMO_DEFAULT,
  });

  // ⭐ Configure form submission mutation
  const { mutate } = useMutation({
    mutationFn: async data => {
      return await Api.createDemo(data);
    },
    onSuccess: data => {
      console.log("Form submitted successfully", data);
    },
    onError: error => {
      console.error("Form submission failed", error);
    },
    onSettled: () => {
      console.log("Form submission process finished");
    },
  });

  return (
    // ⭐ Form render at the root level
    <RgoForm form={form} onSubmit={mutate}>
      {/* omitted */}
    </RgoForm>
  );
}
```

### Form array field registration

Use React Hook Form's `useFieldArray` to handle dynamic arrays of data.

```tsx
/*** @/features/demo/components/DemoForm/DemoForm.tsx ***/

import {
  RgoForm,
  RgoFormSection,
  RgoLabelBox,
  RgoInputText,
  type RgoFormBaseProps,
} from "@vireocodedev/starter-ui";
import { Button, CardActions, CardContent, Grid2 as Grid, IconButton, Typography } from "@mui/material";
import { Add as AddIcon, Delete as DeleteIcon } from "@mui/icons-material";
import { Controller, useFieldArray } from "react-hook-form";
import { useMutation } from "@tanstack/react-query";
import "./DemoForm.css";

export type DemoFormProps = RgoFormBaseProps<Demo>;

export function DemoForm({
  form,
  onCancel,
  readOnly = false,
  group = RgoFormGroup.CREATE,
  ContentComponent = CardContent,
  ActionsComponent = CardActions,
}: DemoFormProps) {

  const form = useRgoForm({
    schema:        /* omitted */,
    defaultValues: /* omitted */,
  });

  const { mutate } = useMutation({
    mutationFn:    /* omitted */,
    onSuccess:     /* omitted */,
    onError:       /* omitted */,
    onSettled:     /* omitted */,
  });

  // ⭐ Initialize useFieldArray for managing dynamic hobbies array
  const { fields, append, remove, update } = useFieldArray({
    control: form.control,
    name: "hobbies",
  });

  return (
    <RgoForm form={form} onSubmit={mutate}>
      <ContentComponent>
        <RgoFormSection label="Personal information">
          {/* omitted */}
        </RgoFormSection>

        <RgoFormSection label="Hobbies">
          <Grid container spacing={2}>

            {/* ⭐ Render each hobby field dynamically */}
            {fields.map(({ id }, index) => (
              <Grid size={12} key={id}>
                <RgoLabelBox
                  label={`Hobby ${index + 1}`}
                  required
                  helperText={
                    <Button
                      startIcon={<AddIcon />}
                      variant="outlined"
                      onClick={() => append("")}
                    >
                      Add Hobby
                    </Button>
                  }
                >

                  {/* ⭐ Use Controller to connect each array item to form state */}
                  <Controller
                    name={`hobbies.${index}`}
                    control={form.control}
                    disabled={readOnly}
                    render={({ field, fieldState }) => (
                      <Box display="flex" alignItems="center" gap={1}>
                        <RgoInputText
                          {...field}
                          error={fieldState.invalid}
                          helperText={fieldState.error?.message}
                        />

                        {/* ⭐ Delete action for removing hobby items */}
                        {!readOnly && (
                          <IconButton color="error" onClick={() => remove(index)}>
                            <DeleteIcon />
                          </IconButton>
                        )}
                      </Box>
                    )}
                  />
                </RgoLabelBox>
              </Grid>
            ))}

            {/* ⭐ Display "No hobbies" message when array is empty */}
            {fields.length === 0 && (
              <Grid size={12}>
                <Typography variant="body1" color="text.secondary">
                  No hobbies
                </Typography>
              </Grid>
            )}

            {/* ⭐ Display array-level error message if present */}
            {form.formState.errors.hobbies?.message && (
              <Grid size={12}>
                <Typography variant="body2" color="error.main" fontSize="0.875rem">
                  {form.formState.errors.hobbies.message}
                </Typography>
              </Grid>
            )}

          </Grid>
        </RgoFormSection>
      </ContentComponent>

      {/* omitted */}
    </RgoForm>
  );
}
```
