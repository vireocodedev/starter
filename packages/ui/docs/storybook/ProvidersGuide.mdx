# Providers guide

Vireo distinguishes between foundational UI providers and integration-specific providers. Applications own which integrations are installed and how they are configured.

## Foundational contracts

- `VireoIconRegistryProvider` supplies the typed icon registry used by `VireoIcon`.
- `VireoConfirmationProvider` supplies promise-based confirmation overlays.
- `VireoProviderComposer` flattens a configured provider tree while preserving provider-specific prop typing.
- `VireoThemeColorMeta` reversibly owns one browser theme-color meta tag.

MUI's `ThemeProvider` and `CssBaseline` remain direct MUI APIs; Vireo does not wrap them.

## Recommended application boundary

```tsx
import {
  VireoConfirmationProvider,
  VireoIconRegistryProvider,
  VireoProviderComposer,
  VireoThemeColorMeta,
  type VireoProviderWrapper,
} from "@vireocodedev/starter-ui";
import { CssBaseline, ThemeProvider } from "@mui/material";
import { QueryClientProvider } from "@tanstack/react-query";

export function AppProviders({ children }: React.PropsWithChildren) {
  const providers = [
    child => (
      <ThemeProvider theme={theme}>
        <CssBaseline />
        <VireoThemeColorMeta />
        {child}
      </ThemeProvider>
    ),
    child => <QueryClientProvider client={queryClient}>{child}</QueryClientProvider>,
    child => <VireoIconRegistryProvider icons={icons}>{child}</VireoIconRegistryProvider>,
    child => <VireoConfirmationProvider>{child}</VireoConfirmationProvider>,
  ] satisfies readonly VireoProviderWrapper[];

  return <VireoProviderComposer providers={providers}>{children}</VireoProviderComposer>;
}
```

The array is ordered outermost to innermost. Every callback uses ordinary JSX, so TypeScript validates the props required by that provider.

## When to use explicit nesting

Prefer explicit JSX when the tree is short, when providers appear in different branches, or when the nesting itself communicates important behavior. `VireoProviderComposer` is intentionally not a dependency resolver and does not provide IDs, priorities, or automatic ordering.

## Integration providers

The legacy Sonner, localization, and TanStack Query wrappers remain deferred to the integrations phase. New applications should prefer the upstream provider APIs until those integration contracts are finalized.
