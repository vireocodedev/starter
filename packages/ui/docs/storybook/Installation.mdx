## 1. Install the Package

```bash
npm install @vireocodedev/starter-ui
```

## 2. Install Peer Dependencies

### Required Dependencies

```bash
# React and Material-UI core
npm install react@^18.3.1 react-dom@^18.3.1
npm install @mui/material@^6.4.1 @emotion/react@^11.14.0 @emotion/styled@^11.14.0
npm install @mui/icons-material@^6.4.3

# Internationalization core
npm install i18next@^25.4.1 react-i18next@^15.4.0
```

### Optional Dependencies (by feature)

```bash
# Temporal form fields
npm install @mui/x-date-pickers@^7.27.0

# Form schemas
npm install @tanstack/react-form@^1.33.5 zod@^3.24.2

# Query handling (RgoQueryClientProvider)
npm install @tanstack/react-query@^5.64.2 axios@^1.7.9
```

### Complete Installation

For all features:

```bash
npm install react@^18.3.1 react-dom@^18.3.1 \
  @mui/material@^6.4.1 @emotion/react@^11.14.0 @emotion/styled@^11.14.0 \
  @mui/icons-material@^6.4.3 i18next@^25.4.1 react-i18next@^15.4.0 \
  @mui/x-date-pickers@^7.27.0 @tanstack/react-form@^1.33.5 zod@^3.24.2 \
  @tanstack/react-query@^5.64.2 axios@^1.7.9
```

## 3. Basic Setup

### Minimal Setup (Required)

```tsx
import React from "react";
import { createTheme } from "@mui/material/styles";
import { RgoThemeProvider } from "@vireocodedev/starter-ui";

const theme = createTheme({
  palette: {
    primary: { main: "#1976d2" },
    secondary: { main: "#dc004e" },
  },
});

function App() {
  return (
    <RgoThemeProvider theme={theme}>
      <YourAppContent />
    </RgoThemeProvider>
  );
}
```

**Note**: You must provide a custom theme. The library does not include a default theme.

## 4. Provider Configuration

Add providers based on the features you need:

### RgoThemeProvider (Required)

Always required for theming and CSS baseline.

### RgoQueryClientProvider (Optional)

Add if using data fetching or server state management:

```tsx
import { RgoQueryClientProvider } from "@vireocodedev/starter-ui";

<RgoThemeProvider theme={theme}>
  <RgoQueryClientProvider>
    <App />
  </RgoQueryClientProvider>
</RgoThemeProvider>;
```

### RgoLocalizationProvider (Optional)

Add if using the `useTranslation` hook:

```tsx
import { RgoLocalizationProvider } from "@vireocodedev/starter-ui";

<RgoLocalizationProvider>
  <App />
</RgoLocalizationProvider>;
```

### RgoConfirmProvider (Optional)

Add if using the `useRgoConfirm` hook:

```tsx
import { RgoConfirmProvider } from "@vireocodedev/starter-ui";

<RgoConfirmProvider>
  <App />
</RgoConfirmProvider>;
```

### AppSnackbarProvider (Optional)

Add if you want toast notifications via `toast()`:

```tsx
import { AppSnackbarProvider } from "@vireocodedev/starter-ui";

<AppSnackbarProvider>
  <App />
</AppSnackbarProvider>;
```

## 5. Complete Setup Example

Full configuration with all providers:

```tsx
import React from "react";
import { createTheme } from "@mui/material/styles";
import {
  RgoThemeProvider,
  RgoQueryClientProvider,
  RgoLocalizationProvider,
  RgoConfirmProvider,
  AppSnackbarProvider,
} from "@vireocodedev/starter-ui";

const theme = createTheme({
  palette: {
    primary: { main: "#1976d2" },
    secondary: { main: "#dc004e" },
  },
});

function App() {
  return (
    <RgoThemeProvider theme={theme}>
      <RgoQueryClientProvider>
        <RgoLocalizationProvider>
          <RgoConfirmProvider>
            <AppSnackbarProvider>
              <YourAppContent />
            </AppSnackbarProvider>
          </RgoConfirmProvider>
        </RgoLocalizationProvider>
      </RgoQueryClientProvider>
    </RgoThemeProvider>
  );
}
```

## 6. Special Components

### RgoVideoStreamPlayer

Requires WebRTC stream server setup. It lives behind its own entry point so that
`ovenplayer` is only resolved by consumers that render a stream:

```tsx
import { RgoVideoStreamPlayer } from "@vireocodedev/starter-ui/video";

<RgoVideoStreamPlayer url="wss://your-stream-server.com/app/stream-name" width="100%" height="100%" autoStart={true} />;
```

## Troubleshooting

- **Missing peer dependencies**: Install the specific packages mentioned in console warnings
- **Theme errors**: Ensure you're providing a valid Material-UI theme created with `createTheme()`
- **TypeScript errors**: Verify all peer dependencies are installed with compatible versions
