# Augmentable Interfaces

![STABLE](https://img.shields.io/badge/STABLE-green?style=flat-square)

Vireo exposes focused registry interfaces that consumer apps can extend via TypeScript **declaration merging**. This pattern gives the library full type-safety without hard-coding application-specific types.

## How it works

Each augmentable interface is declared as an empty `interface` inside `@vireocodedev/starter-ui`. Because interfaces are open in TypeScript, a consumer app can add members via `declare module`:

```ts
declare module "@vireocodedev/starter-ui" {
  interface SomeRegistry {
    myKey: MyType;
  }
}
```

The library's internal generic types then pick up those additions automatically — no wrappers, no extra configuration.

---

## Setup

Create a single `.d.ts` file in your app (e.g. `src/@types/vireo.d.ts`) and make sure it's included by your `tsconfig.json`. All augmentations can live in this one file:

```ts
// src/@types/vireo.d.ts
declare module "@vireocodedev/starter-ui" {
  // extend any of the registries here
}
```

## Full example

A complete `vireo.d.ts` file augmenting the icon and drag-and-drop registries:

```ts
// src/@types/vireo.d.ts
import { type ChamberSide, type Direction, type StreamType } from "@/infrastructure/enums";
import { type APP_ICON_REGISTRY } from "@/setup/icons/icons.registry";
import type React from "react";

declare module "@vireocodedev/starter-ui" {
  interface VireoIconRegistry extends Record<keyof typeof APP_ICON_REGISTRY, React.ComponentType> {}
}

declare module "@vireocodedev/starter-ui/hello-pangea-dnd" {
  interface VireoDraggableIdRegistry {
    convoy: { convoyId: number };
  }

  interface VireoDropZoneIdRegistry {
    chamber: { chamberSide: ChamberSide; chamberDirection: Direction };
    stream: { streamType: StreamType; streamDirection: Direction };
  }
}
```
