## Overview

| Component        | Use Case                | Sorting                          | Pagination |
| ---------------- | ----------------------- | -------------------------------- | ---------- |
| `RgoClientTable` | All data in memory      | Client-side comparator functions | Optional   |
| `RgoServerTable` | Paginated API responses | Server-side sort field strings   | Required   |

Both components share the same base types from `RgoTable` and render identical UI.

## Column Definitions

Columns are defined using `DtBaseColumn<TItem, TSort>`:

```tsx
import type { DtBaseColumn } from "@vireocodedev/starter-ui";

type User = { id: number; name: string; email: string; role: string };

// Client-side column (sort is a comparator function)
const clientColumns: DtBaseColumn<User, (a: User, b: User) => number>[] = [
  {
    id: "name",
    HeaderComponent: () => "Name",
    BodyComponent: ({ item }) => <span>{item.name}</span>,
    sort: (a, b) => a.name.localeCompare(b.name),
    widthPctShare: 30,
    widthPxMin: 120,
  },
  {
    id: "email",
    HeaderComponent: () => "Email",
    BodyComponent: ({ item }) => <span>{item.email}</span>,
    sort: (a, b) => a.email.localeCompare(b.email),
    widthPctShare: 40,
    widthPxMin: 180,
  },
  {
    id: "role",
    HeaderComponent: () => "Role",
    BodyComponent: ({ item }) => <span>{item.role}</span>,
    widthPctShare: 30,
    widthPxMin: 100,
  },
];

// Server-side column (sort is a field name string)
const serverColumns: DtBaseColumn<User, string>[] = [
  {
    id: "name",
    HeaderComponent: () => "Name",
    BodyComponent: ({ item }) => <span>{item.name}</span>,
    sort: "name",
    widthPctShare: 30,
    widthPxMin: 120,
  },
  // ...
];
```

### Column Properties

| Property          | Type                            | Description                                                |
| ----------------- | ------------------------------- | ---------------------------------------------------------- |
| `id`              | `string`                        | Unique column identifier                                   |
| `HeaderComponent` | `React.FC`                      | Renders the column header                                  |
| `BodyComponent`   | `React.FC<{ item: T }>`         | Renders each cell                                          |
| `sort`            | `TSort \| undefined`            | Sort config (comparator for client, field name for server) |
| `align`           | `"left" \| "center" \| "right"` | Cell alignment                                             |
| `widthPctShare`   | `number`                        | Percentage width share                                     |
| `widthPxMin`      | `number`                        | Minimum width in pixels                                    |
| `sticky`          | `boolean`                       | Sticky column (horizontal scroll)                          |

## RgoClientTable

Full-featured table with client-side sorting and optional pagination:

```tsx
import { RgoClientTable } from "@vireocodedev/starter-ui";
import type { PageableParams } from "@vireocodedev/starter-ui";
import React from "react";

function UserTable({ users }: { users: User[] }) {
  const [pagination, setPagination] = React.useState<PageableParams>({
    page: 0,
    rowsPerPage: 10,
    sortBy: "",
    sortDirection: "asc",
  });

  return (
    <RgoClientTable
      data={users}
      columns={clientColumns}
      keyMapper={user => user.id}
      pagination={pagination}
      onPaginationChange={setPagination}
    />
  );
}
```

### Without Pagination

```tsx
<RgoClientTable data={users} columns={clientColumns} keyMapper={user => user.id} disablePagination />
```

## RgoServerTable

Table with server-driven pagination and sorting:

```tsx
import { RgoServerTable } from "@vireocodedev/starter-ui";
import type { PageableParams } from "@vireocodedev/starter-ui";
import { useQuery } from "@tanstack/react-query";
import React from "react";

function ServerUserTable() {
  const [pagination, setPagination] = React.useState<PageableParams>({
    page: 0,
    rowsPerPage: 10,
    sortBy: "name",
    sortDirection: "asc",
  });

  const { data } = useQuery({
    queryKey: ["users", pagination],
    queryFn: () =>
      fetch(
        `/api/users?page=${pagination.page}&size=${pagination.rowsPerPage}&sort=${pagination.sortBy},${pagination.sortDirection}`,
      ).then(r => r.json()),
  });

  return (
    <RgoServerTable
      data={data?.content ?? []}
      columns={serverColumns}
      keyMapper={user => user.id}
      count={data?.totalElements ?? 0}
      pagination={pagination}
      onPaginationChange={setPagination}
    />
  );
}
```

### Server Table Props

| Prop                 | Type                             | Description                                 |
| -------------------- | -------------------------------- | ------------------------------------------- |
| `data`               | `T[]`                            | Current page of data                        |
| `columns`            | `DtBaseColumn<T, string>[]`      | Column definitions                          |
| `count`              | `number`                         | **Total** row count (not just current page) |
| `pagination`         | `PageableParams`                 | Current pagination/sort state               |
| `onPaginationChange` | `SetStateAction<PageableParams>` | State setter                                |
| `keyMapper`          | `(item: T) => string \| number`  | Unique row key                              |

## Composable Primitives

For custom table layouts, use the primitives directly:

### RgoTableCellSortable

Sortable column header cell:

```tsx
import { RgoTableCellSortable } from "@vireocodedev/starter-ui";

<RgoTableCellSortable
  sortDirection={pagination.sortDirection}
  isSorted={pagination.sortBy === "name"}
  onClick={() => handleSort("name")}
>
  Name
</RgoTableCellSortable>;
```

### RgoTablePagination

Pagination controls:

```tsx
import { RgoTablePagination } from "@vireocodedev/starter-ui";

<RgoTablePagination
  count={totalRows}
  pagination={pagination}
  onPaginationChange={setPagination}
  rowsPerPageOptions={[5, 10, 25, 50]}
/>;
```

### RgoTableRowExpandable

Expandable row with accordion:

```tsx
import { RgoTableRowExpandable } from "@vireocodedev/starter-ui";

<RgoTableRowExpandable item={user} columns={columns} AccordionComponent={({ item }) => <UserDetails user={item} />} />;
```

## Pagination State

The shared `PageableParams` type drives both table types:

```tsx
import type { PageableParams } from "@vireocodedev/starter-ui";

const initialPagination: PageableParams = {
  page: 0, // Zero-based page index
  rowsPerPage: 10, // Rows per page
  sortBy: "", // Sort column ID
  sortDirection: "asc", // "asc" | "desc"
};
```

Default rows-per-page options: `[5, 10, 25, 50]` (customizable via `rowsPerPageOptions`).

## Sortable Columns

### Client-Side Sorting

Provide a comparator function on the column's `sort` property:

```tsx
const columns = [
  {
    id: "name",
    sort: (a, b) => a.name.localeCompare(b.name),
    // ...
  },
  {
    id: "age",
    sort: (a, b) => a.age - b.age,
    // ...
  },
  {
    id: "actions",
    // No sort property = non-sortable column
    // ...
  },
];
```

### Server-Side Sorting

Provide a field name string on the column's `sort` property:

```tsx
const columns = [
  {
    id: "name",
    sort: "name", // Sent as pagination.sortBy
    // ...
  },
];
```

The `pagination.sortBy` and `pagination.sortDirection` values are updated automatically when the user clicks a column header. Use them in your API query.

## Expandable Rows

Both table types support expandable rows:

```tsx
<RgoClientTable
  data={users}
  columns={columns}
  keyMapper={u => u.id}
  pagination={pagination}
  onPaginationChange={setPagination}
  isRowExpandable={user => user.hasDetails}
  AccordionComponent={({ item }) => (
    <Box sx={{ p: 2 }}>
      <Typography variant="body2">Additional details for {item.name}</Typography>
    </Box>
  )}
/>
```

| Prop                 | Type                    | Description                   |
| -------------------- | ----------------------- | ----------------------------- |
| `isRowExpandable`    | `(item: T) => boolean`  | Whether a row can be expanded |
| `AccordionComponent` | `React.FC<{ item: T }>` | Content to show when expanded |

## Sticky Headers

Enable sticky headers with a max height constraint:

```tsx
<RgoClientTable
  data={largeDataset}
  columns={columns}
  keyMapper={item => item.id}
  disablePagination
  stickyMaxHeight="600px"
/>
```

| Prop              | Type     | Description                                      |
| ----------------- | -------- | ------------------------------------------------ |
| `stickyMaxHeight` | `string` | CSS max-height value (e.g., `"500px"`, `"80vh"`) |
