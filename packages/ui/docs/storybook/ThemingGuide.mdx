# Theming Guide

![STABLE](https://img.shields.io/badge/STABLE-green?style=flat-square)

Vireo is built on Material UI's theming system. `createVireoTheme` supplies the supported visual foundation and accepts standard MUI theme customization, so applications get coherent defaults without losing MUI extensibility.

## Basic Setup

Every Vireo application must be wrapped in `ThemeProvider`:

```tsx
import { CssBaseline, ThemeProvider } from "@mui/material";
import { createVireoTheme } from "@vireocodedev/ui/theme";

const theme = createVireoTheme({ mode: "light" });

function App() {
  return (
    <ThemeProvider theme={theme}>
      <CssBaseline />
      <YourApp />
    </ThemeProvider>
  );
}
```

Vireo uses MUI's `ThemeProvider` directly. Mount `CssBaseline` explicitly to apply the canonical canvas, selection, and global MUI baseline. The factory enables CSS variables and sets MUI's system reduced-motion policy.

## Custom Palette

Define brand colors through the palette:

```tsx
const theme = createVireoTheme({
  mode: "light",
  palette: {
    primary: {
      main: "#2563eb",
      light: "#60a5fa",
      dark: "#1d4ed8",
      contrastText: "#ffffff",
    },
    secondary: {
      main: "#7c3aed",
      light: "#a78bfa",
      dark: "#5b21b6",
    },
    error: {
      main: "#dc2626",
    },
    warning: {
      main: "#f59e0b",
    },
    success: {
      main: "#16a34a",
    },
    info: {
      main: "#0891b2",
    },
  },
});
```

All Vireo components automatically use the active theme colors. Prefer semantic palette roles (`background`, `text`, `divider`, `action`) and `theme.vireo.surface`, `theme.vireo.border`, and `theme.vireo.focus` over numbered color shades in reusable UI.

## Typography

Customize fonts and text styles:

```tsx
const theme = createVireoTheme({
  typography: {
    fontFamily: '"Inter", "Roboto", "Helvetica", "Arial", sans-serif',
    h1: {
      fontSize: "2.5rem",
      fontWeight: 700,
      lineHeight: 1.2,
    },
    h2: {
      fontSize: "2rem",
      fontWeight: 600,
    },
    body1: {
      fontSize: "1rem",
      lineHeight: 1.6,
    },
    button: {
      textTransform: "none", // Remove uppercase from buttons
      fontWeight: 600,
    },
  },
});
```

## Component Overrides

Override default styles for MUI components used by Vireo:

```tsx
const theme = createVireoTheme({
  shape: {
    borderRadius: 8,
  },
  components: {
    MuiButton: {
      styleOverrides: {
        root: {
          textTransform: "none",
          borderRadius: 8,
          padding: "8px 16px",
        },
      },
      defaultProps: {
        disableElevation: true,
      },
    },
    MuiTextField: {
      defaultProps: {
        variant: "outlined",
        size: "small",
      },
    },
    MuiPaper: {
      styleOverrides: {
        root: {
          borderRadius: 12,
        },
      },
    },
    MuiTableCell: {
      styleOverrides: {
        root: {
          padding: "12px 16px",
        },
        head: ({ theme }) => ({
          fontWeight: 600,
          backgroundColor: theme.vireo.surface.sunken,
        }),
      },
    },
  },
});
```

These overrides affect both MUI components and all Vireo components that use them internally.

## Dark Mode

### Static Dark Theme

```tsx
const darkTheme = createVireoTheme({
  mode: "dark",
  palette: {
    primary: { main: "#60a5fa" },
  },
});

<ThemeProvider theme={darkTheme}>
  <App />
</ThemeProvider>;
```

### Dynamic Theme Switching

```tsx
import { ThemeProvider } from "@mui/material";
import { createVireoTheme } from "@vireocodedev/ui/theme";
import React from "react";

function App() {
  const [darkMode, setDarkMode] = React.useState(false);

  const theme = React.useMemo(
    () =>
      createVireoTheme({
        mode: darkMode ? "dark" : "light",
        palette: {
          primary: { main: "#2563eb" },
        },
      }),
    [darkMode],
  );

  return (
    <ThemeProvider theme={theme}>
      <button onClick={() => setDarkMode(prev => !prev)}>Toggle {darkMode ? "Light" : "Dark"} Mode</button>
      <YourApp />
    </ThemeProvider>
  );
}
```

## Using the useTheme Hook

MUI's `useTheme` hook provides access to the current theme. Import it from `@mui/material` — `ThemeProvider` mounts
MUI's own `ThemeProvider`, so the standard hook works unchanged:

```tsx
import { useTheme } from "@mui/material";

function ThemedComponent() {
  const theme = useTheme();

  return (
    <div
      style={{
        backgroundColor: theme.palette.background.paper,
        color: theme.palette.text.primary,
        borderRadius: theme.shape.borderRadius,
        padding: theme.spacing(2),
      }}
    >
      <p>Current mode: {theme.palette.mode}</p>
      <p>Primary color: {theme.palette.primary.main}</p>
    </div>
  );
}
```

## Extended Palette Colors

MUI allows extending the palette with custom colors. Define them in the theme and use them across Vireo components:

```tsx
// Extend the MUI palette declaration
declare module "@mui/material/styles" {
  interface Palette {
    brand: Palette["primary"];
    neutral: Palette["primary"];
  }
  interface PaletteOptions {
    brand?: PaletteOptions["primary"];
    neutral?: PaletteOptions["primary"];
  }
}

const theme = createVireoTheme({
  palette: {
    brand: {
      main: "#ff6b2b",
      light: "#ff9966",
      dark: "#cc4400",
      contrastText: "#ffffff",
    },
    neutral: {
      main: "#64748b",
      light: "#94a3b8",
      dark: "#475569",
    },
  },
});
```

Use the custom colors with the `sx` prop on any component:

```tsx
<Box sx={{ bgcolor: "brand.main", color: "brand.contrastText", p: 2 }}>Brand colored box</Box>
```
