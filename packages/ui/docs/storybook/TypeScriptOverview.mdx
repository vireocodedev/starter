# TypeScript libraries

Vireo Starter's TypeScript packages provide the reusable browser, data, localization, persistence, navigation, and React UI contracts used by Vireo applications.

## Package family

- **UI** — React and MUI components, hooks, providers, capabilities, and opt-in integrations.
- **History** — framework-free history definitions, record validation, and deterministic diff creation.
- **Infrastructure** — HTTP, connectivity, persistent-state, pagination, and session-lifecycle primitives.
- **Localization** — resource assembly, registration, locale-aware formatting, and translation helpers.
- **Query Engine** — portable filter definitions, compilation, persistence, and execution contracts.
- **SQLite** — browser SQLite runtime, offline replay, hydration, and local-data lifecycle.
- **Shell** — application paths, navigation configuration, redirects, and overlay-history behavior.

Open a package's **Overview** page first, then follow its pages in navigation order. UI additionally contains the complete executable component and hook catalog.
