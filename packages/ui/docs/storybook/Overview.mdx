## What is RGO Front UI?

RGO Front UI provides:

- **Components**: 41 production-ready UI components across 7 categories
- **Hooks**: 19 specialized hooks for forms, confirmations, translations, and more
- **Providers**: 7 modular providers for theming, notifications, localization, and icons
- **Services**: 3 utility services for local storage, offline caching, and web workers
- **TypeScript**: Full type safety with comprehensive type definitions
- **Storybook**: Interactive documentation with live examples

## Component Categories

### Form Components

TanStack-bound form structure and fields are available through `useVireoForm`. Use the `form.*` and `field.*` APIs shown under the Forms Storybook category.

### Data Display Components (11)

Components for presenting data and information:

- **VireoResponsiveTable**: Container-aware desktop and mobile data presentation with controlled pagination, sorting, filters, loading, and scroll restoration
- **VireoIcon**: Standardized icon component using the icon registry
- **VireoIconContainer**: SVG geometry scaler for the standard 24×24 icon coordinate system
- **VireoJsonViewer**: Resilient structured-data viewer with copy feedback
- **VireoLabelBox**: Consistent labeling wrapper for form elements
- **RgoTruncatedText**: Text truncation with expand/collapse
- **VireoToaster**: Responsive, MUI-themed Sonner notification region, available from the dedicated `/sonner` entry point
- **VireoStopwatch**: Live and completed elapsed-duration display
- **RgoVideoStreamPlayer**: WebRTC video streaming with OvenPlayer

### Feedback Components

User feedback and status indication:

- **VireoQueryBoundary**: Suspense loading, safe error presentation, local TanStack Query reset, and opt-in diagnostics, available from `/tanstack-query`

### Layout Components (3)

Page structure and layout:

- **RgoPage**: Full-page layout container
- **RgoPageBody**: Page body content area
- **RgoPageHeader**: Page header with title and actions

### Navigation Components (1)

- **VireoTabs**: Tab navigation with URL state synchronization

### Wrapper Components (3)

Container and composition utilities:

- **VireoFormSection**: Groups fields in a named, container-responsive section
- **VireoFormSectionItem and VireoFormActions**: Own full-row compositions and responsive form actions without direct Grid2 layout
- **VireoInfiniteCanvas**: Pannable and zoomable infinite canvas with grid background

### Miscellaneous Components (1)

- **VireoInitializationBoundary**: Async initialization wrapper with loading state

## Hooks

Specialized functionality hooks:

- **useVireoForm**: TanStack Form integration with Vireo fields and Zod validation
- **useVireoMultiStepForm**: Typed TanStack form with conditional steps, validation-gated navigation, and subscriptions
- **useRgoConfirm**: Modal confirmation dialogs
- **useTranslation**: Internationalization and localization (i18next wrapper)
- **useTranslationLocal**: Built-in front-ui translation strings (8 locales)
- **useTheme**: Theme switching and customization
- **useVireoSearchParamState**: Typed scalar URL state that composes with controls such as VireoTabs
- **useVireoDebouncedCallback**: Trailing callback scheduling with cancellation and flushing
- **useVireoFullscreen**: Observe and control fullscreen ownership for one target element
- **useVireoTransitionPresence**: Retain values safely through transition exits
- **useEffectOnce**: Run effect exactly once (Strict Mode safe)
- **useVireoIcons**: Access the icon registry from VireoIconRegistryProvider
- **useVireoInfiniteCanvas**: Access infinite canvas transform and fullscreen state
- **useVireoMutation**: TanStack Query mutation extension with optional Sonner messages and Zod-validated error details, available from `/tanstack-query`

## Architecture

Provider-based architecture with optional functionality. Applications can flatten the configured tree with `VireoProviderComposer`:

```tsx
<ThemeProvider theme={customTheme}>
  <CssBaseline />
  <VireoThemeColorMeta />
  <VireoIconRegistryProvider>
    <YourApp />
  </VireoIconRegistryProvider>
</ThemeProvider>
```

- **Well Documented**: Interactive examples for every component and hook in Storybook
