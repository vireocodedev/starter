# Vireo UI

Vireo is the MUI-based component and interaction library for vireocodedev Starter applications. It owns reusable UI contracts while applications retain routing, API, persistence, and product-specific policy.

## Package boundaries

- `@vireocodedev/starter-ui` exposes foundational components, hooks, providers, and finalized capabilities.
- `@vireocodedev/starter-ui/forms` exposes the TanStack Form integration and bound `form.*` and `field.*` APIs.
- `@vireocodedev/starter-ui/country` exposes typed country identifiers, localized names, and flag rendering.
- `@vireocodedev/starter-ui/event-source` exposes native EventSource lifecycle management.
- `@vireocodedev/starter-ui/hello-pangea-dnd` exposes typed drag-and-drop composition.
- `@vireocodedev/starter-ui/localization` exposes temporal localization for MUI X fields.
- `@vireocodedev/starter-ui/sonner` exposes notifications and the Vireo toaster surface.
- `@vireocodedev/starter-ui/tanstack-query` exposes query boundaries and mutation integration.

Integration subpaths are intentionally absent from the package root so applications opt into their peer dependencies explicitly.

## Main capabilities

- **Forms** — typed form initialization, validation policy, multi-step flows, container-responsive sections and actions, and bound fields.
- **Tables** — one controlled, container-aware model for desktop and mobile data presentation.
- **Overlays** — dialogs, drawers, docked panels, responsive frames, confirmation flows, and page-overlay orchestration.
- **Page layout** — container-measured pages, headers, bodies, cards, and layout utilities.
- **History** — responsive, nested change-history presentation.
- **Infinite canvas** — controlled pan, zoom, transformed content, and fixed overlays.
- **Unsaved changes** — scoped registration, discard requests, and navigation integration.

## Foundational APIs

- `VireoIcon`, `VireoIconRegistryProvider`, and `useVireoIcons`
- `VireoJsonViewer`, `VireoTruncatedContent`, `VireoStopwatch`, and `VireoStatusDot`
- `VireoTabs`, `VireoSlidingScreenStack`, and `VireoDelayedRender`
- `VireoProviderComposer`, `VireoThemeColorMeta`, and `VireoInitializationBoundary`
- `useVireoDebouncedCallback`, `useVireoFullscreen`, `useVireoSearchParamState`, and `useVireoTransitionPresence`

## Design principles

- Components use the complete Vireo contract: slots, slot props, utility classes, theme defaults, variants, tests, and executable stories.
- Stories show copy-pastable consumer source and intentionally do not use Storybook controls.
- Responsive behavior follows the owning container whenever component behavior depends on available space.
- External runtimes live behind explicit integration subpaths.
- Applications own domain composition and policy; Vireo owns reusable interaction and presentation behavior.

## Getting started

1. Follow the [Installation guide](?path=/docs/documentation-installation--docs).
2. Configure the [foundational and integration providers](?path=/docs/documentation-providers-guide--docs).
3. Review the component and hook stories for executable usage examples.
4. Use the focused integration guides when adopting notifications, TanStack Query, drag-and-drop, or responsive tables.
