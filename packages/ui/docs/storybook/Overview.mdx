# Vireo Starter

This is the shared live-documentation portal for the packages in the Vireo Starter monorepo.

## Documentation structure

- **Documentation** contains repository-level guidance that applies across packages.
- **UI** contains `@vireocodedev/starter-ui` documentation and its complete React component and hook catalog.
- **History** contains executable documentation for the framework-free `@vireocodedev/starter-history` package.
- **JVM** contains conceptual guides and compiled source examples for the Spring Boot libraries.
- **Localization** contains executable documentation for the framework-free `@vireocodedev/starter-localization` package.
- **SQLite** contains executable documentation for the framework-free `@vireocodedev/starter-sqlite` package and its `/offline` entry point.

Every additional library will receive its own top-level section as it completes the same audit and documentation pilot established by History. Framework-free packages own their MDX and executable TypeScript examples; UI owns the shared React-based Storybook host.

## Package boundaries

- UI owns reusable React presentation, interaction, providers, and explicit integration adapters.
- History owns framework-free history definitions, record validation, and deterministic diff creation.
- Localization owns framework-free translation resources, resource assembly, registration, and locale-neutral formatting.
- SQLite owns framework-free OPFS worker persistence, entity operations, offline replay, hydration coordination, and local-data lifecycle.
- Applications own product-specific composition, domain policy, persistence, and transport decisions.

Start with the relevant package's **Overview** page, then follow its pages in navigation order.
