# Primary workflow

One factory builds every Starter-owned namespace for every requested locale. Shipped locales use their localized resources; unshipped locales start from `seedFrom` (`"en"` by default) and receive deeply merged overrides.

The returned trees are isolated: changing one generated locale cannot mutate a shipped resource or a sibling locale.
