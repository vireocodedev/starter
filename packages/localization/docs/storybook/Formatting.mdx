# Number formatting

`formatIntlNumber` is a thin, framework-free `Intl.NumberFormat` boundary. The caller always supplies the locale and therefore retains ownership of effective-locale policy. Options are passed directly to the platform formatter.

Invalid locale or formatting configuration returns the caller's fallback result, or `String(value)` when no fallback is supplied.
