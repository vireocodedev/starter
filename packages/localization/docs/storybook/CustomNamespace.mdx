# Custom namespaces

`createNamespaceResources` applies the same seeded, isolated, deeply merged resource policy to a library- or application-owned namespace. Give the resource shape explicit widened string leaves so translated and overridden values remain accurately typed.

This helper owns resource assembly only. Namespace naming, translation-key versioning, loading, and locale policy remain with the owning package or application.
