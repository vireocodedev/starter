# Late registration

Use `registerStarterResources` when the caller-owned i18next instance is already initialized. It adds every Starter namespace for every requested locale and deliberately overwrites existing values with the generated resource contract, including explicit consumer overrides.

Use `createStarterResources` during initial i18next setup; use this imperative path only when resource loading happens later in the application lifecycle.
