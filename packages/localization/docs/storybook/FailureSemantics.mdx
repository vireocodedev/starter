# Failure semantics

Resource factories reject empty locale sets, blank or duplicate locale identifiers, overrides for locales that were not requested, blank namespaces, and missing seed resources. Configuration mistakes fail at resource creation rather than becoming missing translations later.

Overrides are immutable inputs. Prototype-mutating keys are ignored, and every output locale receives its own deeply isolated plain-object and array resource tree.
