# Record validation

`createHistoryRecordSchema` validates transport-neutral audit records. Its options accept application-owned entity-kind, snapshot, and timestamp schemas, preserving their inferred output types without coupling History to an application model.

The default timestamp accepts a finite epoch number or an ISO date-time containing `Z` or an explicit offset. Supply `timestamp` when a backend uses another deliberate representation.
