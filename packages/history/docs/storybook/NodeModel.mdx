# Node model

`createHistoryNodes` returns groups and field rows. Every node has a typed `path`; field names and string identities remain strings, while numeric identities remain numbers. Consumers must preserve segment types when deriving keys—use a canonical encoding such as `JSON.stringify(path)`, never `path.join(".")`.

Groups carry `added`, `updated`, `removed`, or `unchanged` state. Rows additionally distinguish `moved`. Empty containers may produce meaningful added or removed groups with no children.
