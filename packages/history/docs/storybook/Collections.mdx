# Collections

Use `mode: "set"` when order has no meaning. Use `mode: "ordered"` when a deliberate reorder should produce a `moved` row. Ordered comparison is sequence-aware: inserting or removing an item does not falsely mark every shifted neighbor as moved.

Primitive values identify themselves. Object items use their nested definition's `key`, and identities must be unique within each snapshot.
