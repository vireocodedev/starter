# Failure semantics

Invalid snapshots fail Zod parsing before comparison. Invalid definition configuration fails when `createHistoryDefinition` runs. Array item identities must be strings or finite numbers and unique within each snapshot; invalid or duplicate identities throw rather than silently overwriting an item.

Structural values must be acyclic and supported by the deterministic comparator. Unsupported values throw with a descriptive error instead of disappearing from the audit trail.
