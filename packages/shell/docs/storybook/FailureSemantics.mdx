# Failure semantics

Invalid route definitions fail during definition or sitemap construction. Duplicate keys and patterns, unmounted redirect targets, missing path parameters, detached config pages, duplicate navigation identifiers, and unknown permissions throw explicit errors rather than producing partial shell state.
