# SQLite execution

The executor composes validated filters, free-text search, sorting, whole-row pagination, optional counts, and row mapping over application-injected execution ports.

The resulting request keeps SQL structure and runtime values separate. The worker-side helpers bind the values and validate pagination before preparing a statement.
