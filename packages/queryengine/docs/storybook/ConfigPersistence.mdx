# Config persistence

The config client owns fallback state per instance and delegates persistent operation to an injected request transport. Runtime reset can clear that state through the registered store without relying on package globals.

Worker-side helpers validate identifiers, request names, JSON, and snapshot shape before reading or writing SQLite state.
