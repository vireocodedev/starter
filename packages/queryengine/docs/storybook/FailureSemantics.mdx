# Failure semantics

Query metadata and persisted state are security and correctness boundaries. Invalid state raises a descriptive failure at the closest boundary instead of being ignored, defaulted, or converted into a wider query.

Transport and Zod errors are preserved when no legacy API retry applies, and aborted requests are never retried.
