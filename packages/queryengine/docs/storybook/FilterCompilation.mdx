# Filter compilation

Column bindings explicitly map public filter and sort keys to application-owned SQL expressions. Runtime values are compiled separately as parameters.

Malformed payloads, mismatched entities, unknown fields, duplicate registrations, and invalid typed values fail closed rather than broadening a result set.
