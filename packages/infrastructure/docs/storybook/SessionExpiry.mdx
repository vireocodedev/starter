# Session expiry

Each application authentication boundary owns a `createSessionExpiryChannel` instance. The channel deduplicates expiry notifications and suppresses them during an intentional logout without prescribing redirects, dialogs, or authentication storage.

Subscribers are isolated from one another. Applications can inject listener-error reporting when failures need observability.
