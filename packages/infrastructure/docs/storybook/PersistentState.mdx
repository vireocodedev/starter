# Persistent state

`createPersistentSignal` mirrors one typed storage key into a framework-free Preact core signal. The application owns storage lifetime, serialization, migration, and error reporting.

Writes reach storage before the signal changes, preventing an in-memory value from claiming persistence succeeded when it did not.
