# Connectivity

Browser online state is only a hint. `createConnectivityState` can combine it with heartbeat freshness and explicit backend availability while an injected runtime owns subscriptions and scheduling.

One state instance permits one active runtime owner. Timing policy is validated before any listener or timer is registered.
