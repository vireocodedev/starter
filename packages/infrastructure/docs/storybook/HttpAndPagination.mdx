# HTTP and pagination

Infrastructure accepts an application-configured Axios transport and validates API data with application-supplied Zod schemas. Pageable searches validate rows and the complete metadata envelope.

Filter JSON fails closed: malformed or shape-incompatible data throws before the request begins instead of disappearing and widening the result set.
