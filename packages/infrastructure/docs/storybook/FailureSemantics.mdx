# Failure semantics

Transport data, filter state, persistence, and connectivity lifecycle are correctness boundaries. Invalid state raises a descriptive failure at the closest boundary instead of being logged with sensitive payloads, silently repaired, or converted into broader behavior.

Cancellation remains distinguishable from ordinary failures, and error sanitization deliberately excludes request and response internals.
