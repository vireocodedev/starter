# Private package history

These files preserve the changelogs from the pre-public GitHub Packages line.
Those releases used `@vireocodedev/starter-*` coordinates and were available only
to authenticated internal consumers. Their version numbers are not part of the
public compatibility contract.

The canonical public packages begin together at `0.2.0` under the shorter
`@vireocodedev/*` coordinates documented in
[`identity-and-coordinates.md`](../../roadmap/phase-0/identity-and-coordinates.md).
This archive is historical context, not migration guidance for public consumers.
